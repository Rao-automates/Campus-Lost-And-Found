1. Introduction
TheCampus Lost & Found Portalis a web application designed to help students
and staff report lost items and browse found items posted by others. It solves a common
everyday problem on any campus or institution where items get misplaced and there is
no organized way to reunite them with their owners.
The application will be built usingHTML, CSS, ASP.NET MVC, and C#, covering
the full course technology stack.
2. Problem Statement
When someone loses an item on campus, they have no easy way to check if it has been
found and handed in somewhere. Similarly, someone who finds an item has no reliable
way to reach its owner. Currently people rely on notice boards or word of mouth, which
is slow and ineffective. This portal provides a centralized, searchable solution to this
problem.
3. Objectives
•Allow users to register and log in to the portal.
•Let users post a lost item or a found item with details and an optional photo.
•Allow anyone to browse and search posted items by category or location.
•Let a user mark an item as returned/resolved once it is claimed.
•Build the application using ASP.NET MVC, C#, HTML, and CSS.
4. Key Features
•User Registration & Login— secure accounts using ASP.NET Identity.
•Post Lost Item— title, description, date lost, location, category (e.g. bag,
phone, keys), optional image upload.
•Post Found Item— same fields but from the finder’s perspective.
•Browse & Search— view all active posts, filter by category or location key-
word.
•Mark as Resolved— the post owner can close a listing once the item is re-
turned.
•My Posts— a personal page showing only the logged-in user’s listings.

8. Conclusion
The Campus Lost & Found Portal is a practical and unique web application that addresses
a real problem students face every day. It is straightforward enough to build within
the course timeframe while covering all required technologies: HTML, CSS, ASP.NET
MVC, and C#. The project involves user authentication, database interaction, image
handling, and a clean searchable interface, making it a well-rounded intermediate-level
course project.
